# PDFKit 阅读与批注测试版

Windows 免费账号侧载包现在由 `SIDELOAD` 编译条件选择苹果 PDFKit 阅读器。文献库、文献详情、登录、同步、WebDAV 与现有笔记编辑器继续沿用 Zotero。原 PSPDFKit 阅读器的源代码和依赖暂时保留给普通构建，尚未从整个项目移除；新阅读器的显示、页面缩略图及其“Export PDF with annotations”均使用 PDFKit，不调用 PSPDFKit 渲染。

## 阅读与批注

- 顶部左侧关闭返回文献库，侧边栏按钮打开批注、页面缩略图和目录。iPad 宽屏显示在左侧，iPhone 或窄屏以面板打开。
- 顶部搜索在 PDF 中查找文字；底部页码可直接跳页。关闭重开后恢复 Zotero 保存的阅读页码。
- 顶部“…”提供连续滚动、横向滚动、双页、适应页面、界面外观和带批注导出。
- 长按选中文字，再点击底部荧光笔、下划线或翻译按钮。不同系统版本的选区菜单可能不同，底部工具栏始终提供这些操作。跨页选区按页保存为独立 Zotero 批注。
- 便签按钮在当前选区位置添加评论；没有选区时在可见页中部添加。空评论不会创建新便签。
- 铅笔按钮进入手写模式，可用手指或 Apple Pencil 绘制。再次点击红色铅笔退出，恢复滚动。当前为整页手写模式，没有橡皮擦、套索和笔迹撤销；单条笔迹可在批注列表中删除。
- 颜色按钮选择 Zotero 原有色板。批注列表的详情按钮可复制文字、翻译、编辑评论、改色或删除。删除会同步到 Zotero，操作前需要确认。

新建高亮、下划线、便签和笔迹使用 Zotero 批注条目、正常的修改追踪和原始 PDF 坐标保存，进入现有同步队列。评论编辑只修改对应字段，保留已有颜色、位置、标签。群组只允许有权限的用户编辑自己的批注。真正的跨设备同步仍须用用户库验收。

## 浮动翻译

在设置 → Translation 配置服务、目标语言及按需提供的 API key。选中文字后点击气泡按钮，或在批注详情中选择 Translate annotation。

译文显示在可拖动面板：

1. 拖动标题栏自由移动；页面其他区域继续响应阅读操作。
2. 拖右下角改变宽高，“−”折叠或展开，“×”关闭。
3. Copy 复制译文；从批注发起翻译时，Annotation 打开评论预览，可编辑后保存，保留原评论并追加译文。
4. 同一窗口有可编辑笔记时，Note 可插入原文与译文。

旋转设备或改变 iPad 分屏宽度时，面板会限制在当前安全区域内，避免标题栏被拖出屏幕。译文区域自身支持滚动和选择文字。Apple 系统翻译通过 iOS 18+ TranslationSession 返回结果，首次使用可能需要下载语言；本机模型、支持的语言和识别结果由系统决定。

## 与原版的差异

- 工具栏布局和选区操作有所调整，PDF 页面由 PDFKit 绘制。原 PDF 内容未重新排版。
- 外观菜单控制界面和阅读背景，不保证将 PDF 白色纸面转换为完整的深色或棕褐色模式。
- 已同步的六类 Zotero PDF 批注按原始坐标显示；新建工具目前支持高亮、下划线、便签与笔迹，尚无区域截图、自由文本编辑、标签管理、批量编辑或朗读工具。
- PDF 文件原有的内嵌批注继续显示，但此版本不自动导入为 Zotero 批注，也不在 Zotero 批注列表中编辑它们。
- 源 PDF 不自动写回批注。请在阅读器“…”使用 Export PDF with annotations 导出副本；原文献和数据库同步不受导出影响。文献库其他旧的批注导出入口尚未替换，请优先使用这个新入口。
- 注释文本编辑为纯文本；未改动评论直接保存会保留原有富文本，重新编辑内容会转为纯文本。
- 扫描件没有可选择文字时，需要先进行 OCR；本版本不新增 OCR。
- 标准构建继续使用原阅读器；侧载包仍保留其他旧模块的 PSPDFKit 链接依赖，这不是完全移除 SDK 的重写。

## 真机验收

先用测试文献，确认其他设备同步完成，再覆盖安装；保持相同 Apple 账号和应用标识符。

1. 打开普通 PDF、带页签/目录 PDF、旋转页或裁切页，检查显示、缩放、搜索、页码恢复。
2. 新建多行高亮、下划线、便签和手写，改色、编辑评论，关闭重开确认。
3. 在 Zotero 桌面版或其他设备同步，检查位置、颜色、评论；再在另一端修改，回到当前阅读器检查更新。
4. 在只读群组及其他作者的批注上检查编辑限制。
5. 翻译后移动、缩放、折叠面板，在面板之外滚动和做批注；测试 iPhone 横屏与 iPad 分屏。
6. 导出 PDF 副本，使用系统“文件”或桌面阅读器检查高亮、笔迹和评论；原文件应保持不变。

模拟器测试覆盖批注数据库字段、原始坐标、笔迹、PDFKit 导出重开和浮动面板边界；不替代以上真机手势与跨设备同步验收。
