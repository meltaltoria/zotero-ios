# 本地 PDF 导入与 AI 阅读侧栏

此功能用于本仓库的 PDFKit 侧载版。请先同步已有文库，再使用原 Apple ID 和原应用标识符签名覆盖安装，避免卸载导致本地未同步内容丢失。

## 添加本地 PDF

1. 先把 PDF 保存到 iPad“文件”App 的“下载项”或“我的 iPad”。来自网盘的文件应先完成下载。
2. 在 Zotero Translate 打开“我的文库”或可写的分类，点右上角 **＋ → 添加文件**，选择一个或多个 PDF。
3. 给已有文献添加附件时，打开文献详情，使用“添加附件”。
4. 也可以在“文件”App 中长按 PDF，选择分享/打开方式中的 **Zotero Translate**。系统可能把入口放在“更多”中。此入口导入到“我的文库 → 所有条目”，需要先登录。

导入会复制文件，不移动或删除“文件”App 中的原件。新代码会协调读取文件提供器的 URL，并在操作期间保持安全访问权限；文件名不再二次解码。爱思助手中的“导入文档”并不等于创建 Zotero 数据库条目，应使用上述文件选择入口。免费账号版不包含官方的 Zotero 分享扩展；本版提供的是主 App 的 PDF 打开入口。

## 配置 DeepSeek

打开 PDF，点顶部 **✨ AI 阅读助手**，再点侧栏的齿轮或 **… → API 设置**。

| 设置 | 默认示例 |
| --- | --- |
| API Base URL | `https://api.deepseek.com` |
| 模型 | `deepseek-flash` |
| API Key | 在 DeepSeek 平台申请的自己的密钥 |

示例地址与模型依据 [DeepSeek 官方文档](https://api-docs.deepseek.com/)（2026-10-27）。如服务商以后调整模型，请填写其当前提供的模型名称。DeepSeek 的 API 额度与聊天网页账号的使用额度分别管理；本 App 不提供额度。

其他服务可填写自己的 HTTPS Base URL 或完整 `/chat/completions` 地址、模型名称和密钥。需要支持 Bearer 认证、流式 Chat Completions 和文本 `delta.content`。当前 DeepSeek 官方接口默认使用非思考模式，其他服务不附加 DeepSeek 特有参数。支持 Chat Completions 格式，不代表所有服务商和模型都已实测兼容。

密钥仅保存在本机钥匙串，与翻译设置的密钥分开；不上传到 Zotero，也不保存进聊天文件。不要在聊天窗口或 GitHub 中粘贴密钥。设置中可以移除保存的密钥。

## 边读边问

- iPad 宽度足够时，PDF 在左侧、AI 聊天在右侧。关闭 AI 后恢复阅读空间。较窄窗口/iPhone 使用可展开面板；聊天内容保留。
- 可一键“总结文献”“推荐相关问题”“解读当前页”“解释选中文字”，也可以输入自己的问题。
- 发送前在“提问范围”选择 **全文 / 当前页 / 选中文本**。选中文字模式只发送本次选中的文字；近期对话会一并发送以支持连续追问。
- 回复逐步显示，可以停止、复制。点回复中的页码链接会跳转到 PDF 对应物理页，物理页从 1 开始，可能与论文印刷页码不同。引用由模型生成，须核对原文。
- 点向下箭头查看回复末尾。阅读较早内容时不会持续强制滚动。
- 聊天按 Zotero 用户、文库和附件保存在本机，不跨设备同步。可从 **… → 清除此文献的聊天** 删除本机记录。API 设置独立于翻译设置。

## 文档范围与限制

本版在本机通过 PDFKit 提取文字，再把所选范围、近期对话和问题发送到你设置的 API。不会自动上传原始 PDF 文件。模型回复和你提问中引用的内容会保存在本机聊天记录；没有单独保存用于请求的整段文档上下文。

普通论文的文字在预算内时发送完整文字；超长 PDF 会选取分布在文档各处的节选用于总结，或按关键词与当前页优先选取片段用于提问。侧栏明确显示“全文节选”及覆盖页数，不把节选声称为已读完整全文。每次文档预算约 48,000 字符，近期对话另有约 12,000 字符预算；初次提取最多 1,500 页/约 200 万字符。混合扫描 PDF 中无文字层的页不会自动识别。

本版没有 OCR、图片理解、图表结构识别、联网检索或外部文献检索。双栏阅读顺序、公式符号等也受 PDF 自身文字层影响。API 无权限、余额不足、限流、网络中断、非兼容流式响应会显示错误；未完成回复会标为不完整，不作为完整回答传给后续请求。

## 安装后的验收

1. 用含中文/空格/百分号文件名的 PDF 测试“＋ → 添加文件”和“文件 → 打开方式”，确认能打开、原件仍在。
2. 用 5–10 页有文字层的论文测试总结、当前页问答、选中文本问答，点页码返回原文核对。
3. 在输出中点“停止”，再发新问题；确认旧请求不会覆盖新回复。关闭并重新打开同一论文，查看记录是否保留。
4. 测试横竖屏、分屏、键盘遮挡、深浅色以及与批注/拖动翻译面板一起使用。
5. 打开另一篇论文，确认聊天独立。最后同步一次，确认 PDF 与批注仍能在 Windows Zotero 中打开。

云端编译与模拟测试无法代替你设备上的文件提供器、键盘、真实 API 和签名环境验收。测试使用模拟 API 数据，不消耗你的服务商额度。
