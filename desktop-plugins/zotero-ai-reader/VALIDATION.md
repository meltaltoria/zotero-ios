# 版本 1.0.1 验证记录

本包为 Windows 桌面 Zotero 设计，manifest 声明兼容 Zotero 7–10，使用标准的 JavaScript / XHTML / CSS 插件接口，无平台原生二进制依赖。1.0.1 将最高兼容版本从 `9.*` 更新为 `10.*`，修复 Zotero 10.0.7 在安装前拒绝旧包的问题；插件 ID 保持一致。

## 已完成

- 9 项核心自动测试通过：服务地址校验、流式数据分块与中文、错误响应、非流式响应、材料截断、历史轮次、模型 Token 字段、HTML 转义、密钥脱敏。
- 23 项浏览器界面与本地 HTTP 集成检查通过：选区转入边栏、材料截断提示、流式与非流式问答、停止生成、失败重试、文献间会话隔离、复制、笔记写入适配、服务预设、凭据分地址保存与删除、停用清理等。
- 检查了 Zotero 7.0.32 和 9.0.6 官方 Linux 发布包内的边栏注册接口，所用注册字段存在。
- 核对了 Zotero 官方 `10.0.7` 标签中的 `ItemPaneManager.registerSection`、阅读器选区事件注册 / 注销、`getByTabID`、`PreferencePanes`、插件启动沙箱及 `Item.attachmentText` 接口。边栏注册和设置页实现文件与之前核对的接口版本一致。
- JavaScript 语法、XHTML XML 解析、XPI 根目录结构、ZIP CRC 和 SHA-256 校验完成。

## 验证边界

- 浏览器集成检查使用本地模拟的 OpenAI 兼容 HTTP 服务；Zotero 的条目、密码管理器和笔记接口使用测试适配器。它验证了插件调用逻辑，不能替代真实 Zotero 端到端运行。
- 曾尝试在独立临时配置中启动官方 Linux Zotero 7.0.32 和 9.0.6；当前云环境的主目录只读，Zotero 在处理指定配置之前仍需初始化其主目录注册信息，因而报“profile cannot be loaded”。该测试未通过启动阶段，未据此宣称插件已在真实 Zotero 中安装运行。
- 当前没有 Windows GUI 执行环境，尚未进行 Windows / Zotero 10.0.7 实机安装验证；接口源码核对及版本声明修复不能替代真实桌面端到端运行。
- 未使用真实服务密钥发起付费模型调用；实际服务连通性与模型权限需安装后用“保存并测试连接”确认。

测试脚本随源码包提供。发布 XPI 不包含测试脚本、模拟服务、配置目录或测试凭据。
