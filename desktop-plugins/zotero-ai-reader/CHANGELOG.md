# 更新记录

## 1.0.3

- 修复“可以安装、API 可用，但边栏空白”的问题：Zotero 为整个折叠区域设置本地化 ID，原先的 Fluent 消息正文会替换区域内的表单。标题改用 `.label`，边栏图标改用 `.tooltiptext` 和 `.aria-label`，保留控件并消除图标旁竖排文字。
- 打开 AI 边栏时使用 Zotero 的 `getPane()`，正确处理原生注册 ID 中的转义字符。
- 在真实 Zotero 10.0.7 中文和英文界面中分别通过 50 项检查；检查本地化后的 DOM 仍连接于窗口、控件具有可见尺寸，并实际点击发送、复制、保存笔记、停止和设置。
- 保留 1.0.2 的失败复现报告和示例截图。此前检查持有已被移出页面的控件对象，未能发现本地化后的空白界面；新版测试覆盖了这一时序。
- 升级后需完全退出并重启 Zotero；原有服务配置和密钥沿用。

## 1.0.2

- 补齐安装器强制要求的 `applications.zotero.update_url`，提供实际 GitHub 更新源和带 SHA-256 的更新元数据。旧 1.0.1 的原生安装错误码为 `-3`，新版在 Zotero 10.0.7 中通过校验并完成安装。
- 使用原生通道读取 XPI 内的 CSS，避免将 `jar:` 地址交给 HTTP URL 解析器而导致启动失败。
- 使用 XHTML 解析静态边栏模板，保留真实 Zotero 窗口中的输入框和按钮。
- 修正 Gecko 匿名 XHR 的创建方式，以及设置脚本先于 XHTML 插入的生命周期处理。
- 通过官方 Linux Zotero 10.0.7 的 33 项原生安装和功能检查；另通过 9 项核心测试及 23 项浏览器 / 模拟 HTTP 检查。

将最高兼容版本改为 `10.*`。该版本仍缺少 `update_url`，不能作为当前安装包使用。

初始版本。请使用 1.0.3 或更新版本。
